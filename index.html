Two instruments, one discipline: package intelligence for the dependencies you choose, and CLI analytics for the command-line tools you ship.

Read the docs View on GitHub

■ Package intelligence

Is this dependency healthy?

One command combines registry metadata, download activity, release history, GitHub signals, dependency data, and security advisories into a single health picture — across PyPI, npm, crates.io, Homebrew, Go, and CRAN. In the terminal, in reports, or over MCP for coding agents.

pip install secchi

■ CLI analytics

How is your CLI actually used?

A one-line shim records which commands and flags run, where they fail, and whether a human or an agent was driving — locally first, into DuckDB, with command paths and flag names only. Never argument values, never error messages.

cargo install secchi-cli-analytics
  • Local-first: useful with zero network, zero account
  • Structure, not content — enforced at the schema level
  • Off with one switch: SECCHI_ANALYTICS=0
  • Delete everything: secchi analytics purge

Real output, not a mockup

Captured from the actual tools. The analytics data is the tool measuring its own invocations — including that an agent, not a human, ran them.
