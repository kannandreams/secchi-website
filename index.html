■ Package intelligence

Is this dependency healthy?

One command combines registry metadata, download activity, release history, GitHub signals, dependency data, and security advisories into a single health picture, across PyPI, npm, crates.io, Homebrew, Go, and CRAN. In the terminal, in reports, or over MCP for coding agents.

  • PyPI
  • npm
  • crates.io
  • Homebrew
  • Go
  • CRAN
$ uvx --from secchi secchi dashboard duckdb
$ uv tool install secchi
$ pip install secchi

■ CLI analytics

How is your CLI actually used?

Think Google Analytics, but for a command line, built the opposite way around. One line of setup, and you'll see which commands and flags people actually use, where things fail, and whether a human or an AI agent was driving.

It only ever records command and flag names, never the values you typed, never error messages. If a captured value happens to look like a secret, an API key, a token, an email, it's redacted before it's ever written to disk.

$ cargo install secchi-cli-analytics
  • Local-first: useful with zero network, zero account
  • Redaction runs even on values you explicitly allow through
  • Off with one switch: SECCHI_ANALYTICS=0
  • Delete everything: secchi analytics purge

A local TUI dashboard for this data ships next.
